# Images

`gallery/before-1.jpg` … `after-3.jpg` and `og-cover.jpg` are solid-color
placeholders generated for layout purposes only. Replace them with real
photos before launch — keep the same filenames (or update the `src`
attributes in `index.html` if you rename them).

## Before/after gallery

- Recommended size: 800x600px (4:3), JPG, under 300KB each.
- Shoot "before" and "after" from the same angle/distance so the slider
  comparison lines up.
- Naming pattern already wired into `index.html`:
  `before-1.jpg` / `after-1.jpg`, `before-2.jpg` / `after-2.jpg`, etc.
- Add a 4th pair by copying one of the `.ba-slider` blocks in the
  Gallery section of `index.html` and updating the numbers.

## Social preview

- `og-cover.jpg`: 1200x630px, shown when the link is shared on
  Facebook/iMessage/etc.

## Favicon

- Add a real `favicon.ico` (32x32) to this folder. Not included —
  currently missing, which just means browsers show a default icon.
